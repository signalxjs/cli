# About

Built with [@sigx/ssg](https://sigx.dev/ssg/):

- File-based routing — `src/pages/about.mdx` is `/about`
- MDX: Markdown with components
- Syntax highlighting with Shiki
- Islands: components hydrate only where you add `client:*`
- Sitemap, robots and a search index out of the box
